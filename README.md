# 📚 شیلاناگرمیانی - Shilanagarmiany Academic Hub

**وێبسایتی پرتووکخانەی زانستی و ئەکادیمی بە پاڵپشتی AI**

---

## 🎯 مەبەست

وێبسایتی **شیلاناگرمیانی** بۆ خوێندکاران، پەژوهێران و پێشامەرگە دروست کراوە، بۆ:

✅ **ڕاپۆرتی ئەکادیمی** - Academic Reports  
✅ **توێژینەوەی زانستی** - Research Papers  
✅ **تێزنامە و ماستەرنامە** - PhD Dissertations & Master's Theses  
✅ **ورکشاپ و سمینار** - Workshops & Seminars  
✅ **یارمەتیدەری AI** - AI-Powered Copilot  
✅ **فایلی Microsoft Office** - Word, PDF, Excel, PowerPoint  

---

## 🌟 تایبەتمەندیەکان

### 1️⃣ **سیستەمی باربکردنی فایل**
- دەتوانیت **Word (.docx)**, **PDF**, **Excel (.xlsx)**, **PowerPoint (.pptx)** یاخود **Text** فایلەکانت بارب بکەیت
- ئۆتۆماتیکی **قەبارە و جۆری فایل** نیشاندەدات
- فایلەکان لە **LocalStorage** کۆدیت دەکێت

### 2️⃣ **چاتی زیرەک (AI Copilot)**
```
🤖 یارمەتیدەری AI بە کوردی
- وەڵامی ئەکادیمی لە پێشەوە برنامە کراو
- تێگەیشتن لە کلیدواشەکانی زانستی
- یارمەتی لە ڕاپۆرت، تێز، ورکشاپ
```

### 3️⃣ **ڕیزبەندی فەرمی**
- **Navigation Bar** - جوڵانەوە ئاسان
- **Hero Section** - پێشکیشی جوانی
- **Grid Layout** - ریزبەندی مۆدۆڕنی کاردەکان
- **Responsive Design** - لە هەموو سنوری کۆمپیوتەر و مۆبایل کار دەکات

### 4️⃣ **ڕەنگی کرێم (Cream Theme)**
- رنگی بنیادی: `#F5E6D3` (Cream)
- رنگی تیرە: `#8B6F47` (Brown)
- ڕەنگی سپی: `#FFFFFF` (White)
- **Elegant & Professional** شێوازی ئەکادیمی
